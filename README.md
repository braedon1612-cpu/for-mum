# For Mum

A personal digital card for Mum, combining a heartfelt message with a gentle animated presentation.

## Features

- Pastel gradient background and a centered card.
- Floating hearts and a pulsing button.
- An additional message fades in after clicking the button.

## Run locally

Clone the repository:

```sh
git clone https://github.com/braedon1612-cpu/for-mum.git
cd for-mum
```

Open `./index.html` in a modern browser. No package installation or build step is required. HTML, CSS and JavaScript run in the browser.

## Project structure

- `index.html` — card content, CSS animations and message-reveal JavaScript.

## Customization and checks

Edit the page text and styles in the HTML file. Keep referenced asset filenames and capitalization consistent. After changes, reload the page and check its layout on desktop and mobile, then exercise each interactive control. No automated test suite is included.
